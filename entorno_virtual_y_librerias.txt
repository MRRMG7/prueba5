====================================================================
GUÍA DE ENTORNO VIRTUAL, PYTHON Y LIBRERÍAS REQUERIDAS
====================================================================

1. REQUISITOS PREVIOS DEL SISTEMA
---------------------------------
- Python: Versión 3.10, 3.11 o 3.12 (recomendado Python 3.14.4
) instalada en el sistema operativo.
- Gestor de paquetes: 'pip' actualizado.
- Base de datos: MySQL Server 8.0

2. INSTALACIÓN DE LA VERSIÓN DE PYTHON
--------------------------------------
- Windows: Descargar el instalador desde https://www.python.org/downloads/
  * IMPORTANTE: Marcar la casilla "Add Python to PATH" durante la instalación.
- Linux (Ubuntu/Debian):
  sudo apt update
  sudo apt install python3 python3-venv python3-pip
- macOS:
  brew install python@3.12

Verificar la instalación ejecutando en terminal:
  python --version  (o python3 --version)

3. CREACIÓN Y ACTIVACIÓN DEL ENTORNO VIRTUAL (venv)
----------------------------------------------------
Se recomienda crear un entorno virtual para aislar las dependencias del proyecto:

En Windows (PowerShell / CMD):
  cd ruta/a/tu/proyecto
  python -m venv venv
  .env\Scriptsctivate

En Linux / macOS (Terminal):
  cd /ruta/a/tu/proyecto
  python3 -m venv venv
  source venv/bin/activate

Una vez activado, el indicador de la consola mostrará '(venv)' al principio de la línea.

4. INSTALACIÓN DE LIBRERÍAS / DEPENDENCIAS
-------------------------------------------
Con el entorno virtual activado, instala todos los paquetes necesarios ejecutando:

  pip install fastapi uvicorn sqlalchemy pymysql pydantic python-jose

Si deseas instalar paquetes opcionales para encriptación Bcrypt:
  pip install bcrypt

Resumen de librerías principales utilizadas:
- fastapi: Framework web para la construcción de la API REST.
- uvicorn: Servidor ASGI de alto rendimiento para ejecutar FastAPI.
- sqlalchemy: ORM para la interacción y mapeo de objetos en MySQL.
- pymysql: Driver de conexión entre Python y MySQL.
- pydantic: Validación de esquemas de datos y serialización JSON.
- python-jose: Manejo de autenticación mediante JSON Web Tokens (JWT).

5. DESACTIVAR EL ENTORNO VIRTUAL
--------------------------------
Cuando termines de trabajar en el proyecto, puedes salir del entorno ejecutando:
  deactivate

### Soluciones para trabajar con tu proyecto

#### Opción 1: Usar `python3` en todos los comandos (Recomendado)
Cada vez que ejecutes un comando en la terminal, utiliza `python3` en lugar de `python`:

* **Crear el entorno virtual:**
  ```bash
  python3 -m venv venv
  ```
* **Activar el entorno virtual:**
  ```bash
  source venv/bin/activate
  ```
  *(Una vez activado el entorno virtual, el comando `python` y `pip` ya funcionarán directamente dentro de la sesión).*
