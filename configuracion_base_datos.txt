====================================================================
CONFIGURACIÓN DE BASE DE DATOS Y CADENA DE CONEXIÓN (MYSQL)
====================================================================

1. ESTRUCTURA Y CREACIÓN DE LA BASE DE DATOS
--------------------------------------------
El proyecto utiliza una base de datos relacional MySQL llamada 'logistica_db'.

Para crear las tablas e insertar los datos iniciales de prueba (Seed Data):
1. Abre tu cliente MySQL (MySQL Workbench, phpMyAdmin o línea de comandos).
2. Ejecuta el archivo de script SQL 'baseDatos.sql' (o 'baseDatos_corregido-v2.txt'):

   mysql -u root -p < baseDatos.sql

El script creará automáticamente:
- Base de datos: `logistica_db`
- Tablas: `usuarios`, `clientes`, `conductores`, `vehiculos`, `pedidos`
- Usuarios de prueba predeterminados:
  * Admin: usuario 'admin', contraseña '123' (Rol: ADMIN)
  * Conductor: usuario 'rsilva', contraseña '123' (Rol: CONDUCTOR, Ref: 1)
  * Cliente: usuario 'jperez', contraseña '123' (Rol: CLIENTE, Ref: 1)

2. CÓMO CAMBIAR LA CADENA DE CONEXIÓN EN EL BACKEND
--------------------------------------------------
En el archivo principal del backend (ej. `backend.py`), ubica la sección 
"2. CONFIGURACIÓN DE BASE DE DATOS" donde se define la constante `DATABASE_URL`:

Sintaxis estándar de SQLAlchemy para MySQL con PyMySQL:
  DATABASE_URL = "mysql+pymysql://<USUARIO>:<CONTRASEÑA>@<HOST>:<PUERTO>/<NOMBRE_BD>"

Ejemplo por defecto (Entorno Local):
  DATABASE_URL = "mysql+pymysql://app_user:password123@localhost:3306/logistica_db"

Casos de ajuste según el entorno:
- Si usas el usuario 'root' de MySQL sin contraseña en localhost:
  DATABASE_URL = "mysql+pymysql://root:@localhost:3306/logistica_db"

- Si tu MySQL tiene contraseña para 'root':
  DATABASE_URL = "mysql+pymysql://root:MiPasswordSeguro@localhost:3306/logistica_db"

- Si la base de datos está en otro equipo dentro de la red local (ej. IP 192.168.1.50):
  DATABASE_URL = "mysql+pymysql://app_user:password123@192.168.1.50:3306/logistica_db"

3. VERIFICACIÓN DE CONEXIÓN
---------------------------
Al iniciar el servidor FastAPI, SQLAlchemy verificará automáticamente la conexión 
gracias al parámetro `pool_pre_ping=True`. Si las credenciales o la IP son incorrectas,
el servidor arrojará un error de conexión `OperationalError`.
